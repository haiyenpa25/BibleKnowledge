# Code Review

Review the final diff for:

- correctness
- regressions
- security
- concurrency problems
- data integrity
- API compatibility
- missing edge cases
- missing tests
- unnecessary complexity
- dead code
- accidental generated files
- secret leakage

Prioritize findings by impact.

Do not approve code merely because tests pass.
