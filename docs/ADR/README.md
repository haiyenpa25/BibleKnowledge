# Architecture Decision Records (ADR)

This directory contains Architecture Decision Records documenting significant architectural decisions, their context, and consequences.

## Format
Each ADR should follow the standard structure:
- **Title**: `ADR-XXXX: Short Descriptive Title`
- **Status**: Proposed / Accepted / Superseded / Deprecated
- **Context**: What problem are we solving? What are the constraints?
- **Decision**: What did we decide to do?
- **Consequences**: What becomes easier, what becomes harder?
